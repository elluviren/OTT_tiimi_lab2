# OTT_tiimi_lab2
Ohjelmistotuotannon työkalut_tiimitehtävä lab2

## Workout Tracker App

Sovellus toimii workout trackerina, jonka avulla käyttäjä voi:
- tallentaa harjoituksia
- seurata treenejä
- tarkastella aiempia suorituksia

## Käyttö

Sovellus mahdollistaa harjoitusten lisäämisen ja tarkastelun yksinkertaisella käyttöliittymällä.

## Tekijät

Projektin ovat toteuttaneet kurssin opiskelijat tiimityönä.
